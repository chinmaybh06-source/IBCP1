# Indian Business Cycle Predictor — deployable static build

This is a zero-backend static web app. It works on mobile browsers and can be hosted on any static host.

## Fastest deployment

1. Upload `index.html` to a static hosting service such as Netlify Drop, GitHub Pages, Cloudflare Pages, or Vercel.
2. The site requires no build command and no environment variables.
3. Use the generated public URL as the website.

## Important
The current values are illustrative demo data. For a production economic research tool, connect a backend/data pipeline to verified Indian sources, add data-vintage handling, revisions, backtesting and calibrated probabilities.
